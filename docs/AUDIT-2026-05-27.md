## Architectural reminders relevant to this audit

- **Vendor.Watch boundary**: VW (`/Users/sme/NEL/vendor-watch-v2`) owns vendor questionnaires, the vendor catalog, and vendor claims. DPC reads via `Vw*` Prisma stubs; never writes those tables; doesn't reimplement workflows that already exist in VW. See `CLAUDE.md` in vendor-watch-v2.
- **i18n**: bilingual EN/ES is complete across the dashboard surface AND the docs section. Adding a third language is `cp en.json fr.json` + add to `locales` in `src/i18n/config.ts` + translate. DB content (`AssessmentTemplate.title` etc.) is the one remaining surface — deferred until a customer asks.
- **Color tokens**: `--primary` is `#53aecc` warm blue, `--destructive` is `#f59e0b` amber (NOT red). For warning states (needs-review, expiring-soon), use `text-yellow-600` / `bg-yellow-50` / `border-yellow-500/40` — matches the existing precedent in `ai-systems/page.tsx` and `assessments/auto-fill/page.tsx`. Never use raw `bg-red-*` or `bg-green-*`.
